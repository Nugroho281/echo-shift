ECHO SHIFT is a time-loop stealth puzzle: a thief in a neon museum records every move, then resets the timeline so a ghost Echo repeats the loop — holding pressure plates, killing lasers, and distracting drones while the thief grabs the artifact and escapes.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
